# AirplayAtTheCrib

Make an existing Roku appear in native AirPlay menus when Wi-Fi discovery is blocked.

## Always-on Linux service

Run one Bluetooth discovery beacon on a nearby Linux machine. iPhones, iPads and
Macs discover the Roku over Bluetooth, then stream directly to it over Wi-Fi.
Nothing needs installing on the casting devices. The server does not carry video.

The beacon approach has been tested with a Roku Select Series TV and a Mac.
Senders still need IP connectivity to the TV and must be within Bluetooth range
of the server. iPhone/iPad compatibility and coverage need validation on your devices.
